# JS Арена

Мини-игры для изучения JavaScript. Работает как приложение на телефоне (PWA) и **без интернета**.

## Игры

| Игра | Чему учит |
|---|---|
| 🔮 Угадай вывод | читать код и понимать, что он сделает (типы, области видимости, методы массивов) |
| 🐞 Найди баг | замечать типичные ошибки: `=` вместо `===`, потерянный `return`, опечатки |
| 🧩 Собери код | порядок строк и структуру функций и циклов |
| ✍️ Заполни пропуск | методы и операторы (`map`, `filter`, `reduce`, `??`, `?.` и др.) |
| ⚡ Тип-блиц | странности `typeof` на скорости |

Раунд — 10 вопросов, 3 жизни. За ответы дают XP, ранги идут от «Новичка» до «Архитектора». Вопросы, на которых ошибся, приложение показывает чаще.
Прогресс хранится в браузере телефона (localStorage).

## Как выложить на GitHub Pages (бесплатно)

1. Создай репозиторий на github.com (например `js-arena`), публичный.
2. Загрузи в него **все файлы из этой папки** (кнопка *Add file → Upload files*). Файл `index.html` должен лежать в корне репозитория.
3. *Settings → Pages → Build and deployment*: Source = **Deploy from a branch**, Branch = **main**, папка **/(root)** → *Save*.
4. Через минуту-две сайт откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/js-arena/`.

## Как поставить на телефон

- **iPhone (Safari):** открой ссылку → кнопка «Поделиться» → *На экран «Домой»*.
- **Android (Chrome):** открой ссылку → меню ⋮ → *Установить приложение* (или *Добавить на главный экран*).

После первого открытия приложение работает офлайн.

## Как добавлять свои вопросы

Все вопросы лежат в `data.js`. Скопируй любой соседний вопрос и поменяй текст:

- `predict` — `c` код, `a` правильный вывод, `w` три неправильных, `why` объяснение
- `bugs` — `lines` строки, `bug` номера строк с ошибкой (с нуля), `fix`, `why`
- `assemble` — `t` задача, `lines` строки в правильном порядке, `out` что должен вывести код
- `gaps` — `t`, `c` код с `___`, `o` варианты, `a` правильный, `out`, `why`
- `types` — `e` выражение, `a` что вернёт `typeof`

## Важно при обновлении

Приложение кэширует файлы для офлайн-режима. После изменений открой `sw.js` и увеличь номер: `const VERSION = 'v2';` — тогда телефон подтянет новую версию.
